## 修复空表格单元格被压塌

- 用户截图：刚插入的全空表格行高明显小于填了内容之后，视觉上差太多。
- 根因：空单元格没有任何行盒，高度只剩 `padding: 7px 12px`（15px）；
  有内容时多出一行 line-height（41.3px）。`table-cell` 上 `min-height` 不生效，
  给 `th/td` 设 `height` 会把有内容的行也一起撑高，改变既有排版。
- 方案：`widgets.js` 的 `buildRow` 给 `c.text` 为空的格子打 `is-empty` class；
  `base.css` 用 `.cm-table-wrap .is-empty::after { content: "\200b" }` 补一个零宽文本行。
  高度自动跟随主题 font-size / line-height；伪元素内容不属于 DOM 文本节点，
  不污染 `textContent`、选中复制与单元格就地编辑。
- 为什么不用 `:empty`：表头 `th` 里恒有 `.cm-table-resize` 拖拽手柄，`:empty` 不匹配，
  实测只有数据行被撑高、表头仍矮 15px。
- 量化（真实应用 iframe + `?debug=1`）：修复前空行 15px / 有内容 41.3px，差 26.3px；
  修复后两者都是 41.3px，表头与数据行都一致。端到端断言 10/10。
- 测试文档注意：`scanTables` 会把「表格中间单个空行」并入同一张表，
  两个表格之间必须放一段普通正文，否则会合并成一个 widget。
- iframe 测试注意：必须在 iframe 导航完成后再取 `contentDocument`，
  否则拿到的是 about:blank 的文档（表现为 `editor=false`、`lines=0`）。
- Vite 构建到临时目录通过。

## 修正：左端按钮是「隐藏标签栏」，不是切换侧栏

- 用户纠正上一轮的理解错误：要的是把**文档标签栏这一整行隐藏掉**，不是打开/收起文件树或大纲。
- 改为：`DocumentTabs.vue` 左端 `#tabs-hide` 点击发出 `toggle-tabs` →
  `shell.toggleTabsVisible()` → `v-if="shell.tabs.length && shell.tabsVisible"` 让整行消失，
  编辑区上移 30px（实测 30.0 → 0.0）。
- 恢复入口（避免关掉找不回来）：状态栏新增 `#st-tabs`（`PanelTop`，`is-on` 反映显隐）、
  「视图 → 显示文件标签栏」菜单项；两者都走同一个 `toggle-tabs` 命令。
  首次隐藏时 `flash` 一次可恢复提示（每会话一次，不反复打扰）。
- 偏好持久化：`storage-keys.js` 加 `TABS_VISIBLE_KEY = "plume.tabsVisible"` 并纳入
  `SETTINGS_KEYS`（参与设置备份）；`shell.js` 加 `tabsVisible` / `setTabsVisible` /
  `toggleTabsVisible`，读写 localStorage 带 try/catch。
- i18n 替换上一轮的 `tabs.toggleSidebar*`，新增 `tabs.hide*` / `status.toggleTabs*` / `menu.showTabs`。
- 验证 15/15：组件层显隐与状态栏同步、编辑区上移 30px、localStorage 与跨会话恢复、
  runtime 命令接线、视图菜单含新项；Vite 构建通过。
- 注意：隐藏标签栏后切换文档靠「文件 → 最近文件」/ `Ctrl+Shift+P` 快速打开，
  或先恢复标签栏；标题栏始终显示当前文件名。
