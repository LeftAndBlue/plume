## Plume logo 重设计（字母版，已落地）

- 用户否定第一版「极简羽毛」方案，评价「毫无设计感」，要求**用字母**重做，且要突出 **Markdown** 与**实时预览**。
  结论：用户要的「设计感」= 概念性巧思 / 负空间双重含义 / 几何构造，不是通用具象图标；
  倾向字母字标、结构严谨、留白大气。以后做视觉方案优先往这个方向走。
- 最终主推并落地：**A · P / 实时窗**。几何字母 P（一根 120 宽连续笔画，非字体），
  其**内孔（负空间）即实时预览窗**：左为青绿 `#` 源码、中间编辑光标、右为渲染后的标题行 + 两行正文。
  一个字母同时讲清 Plume / Markdown / 所见即所得。深墨圆角方章 + 浅蓝→青绿笔画，沿用原品牌色。
- 另出两个备选：B「双态」（左右等大 P，线稿源码态 vs 实心渲染态，中央分栏）、
  C「字标」（实心 P + 内孔 `#` + 右侧光标，最克制）。
